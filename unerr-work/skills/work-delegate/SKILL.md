## Delegation map

unerr-lead frames the work — audience, goal, structure, acceptance criteria — before any deliverable exists. Spawn it first when the scope is undefined or a judgement call is needed.

unerr-researcher gathers and digests source material — web research, existing-document inventory, source reading. Spawn it when the brief needs facts nobody supplied. It returns a digest only; it never drafts.

unerr-drafter produces the deliverable — document, deck outline, spreadsheet, memo — once the shape is set. Spawn it as the default executor for any task with a clear brief.

unerr-reviewer checks a finished deliverable against the brief and reports findings. It has no edit tools. Spawn it after unerr-drafter or unerr-specialist finishes, before the deliverable ships.

unerr-specialist runs one scoped task outside this flow. Spawn it only when the user names it directly ("use unerr-specialist"). Never spawn it automatically.

## Order

unerr-lead (frame) → unerr-researcher (gather, if needed) → unerr-drafter (produce) → unerr-reviewer (check against brief). Skip a step only when its output already exists — a supplied outline skips unerr-lead, supplied source material skips unerr-researcher.
