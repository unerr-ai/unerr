# Security policy

## Supported versions

unerr is pre-1.0 and ships one line of releases. Only the latest published
version (npm `latest` tag / most recent GitHub release) gets security fixes.
Please upgrade before reporting — the issue may already be fixed.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security problem.

The primary way to report one privately is through GitHub's private
vulnerability reporting:

1. Go to the [Security tab](https://github.com/unerr-ai/unerr/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue: what it is, how to reproduce it, and what it affects.

If you cannot use GitHub for any reason, email **jaswanth@unerr.dev** instead.
Say "security" in the subject line. Please do not include a working exploit in
the first email — describe the issue and we will agree a channel for details.

## What to expect

- We aim to acknowledge new reports within a few business days.
- We'll keep you updated as we investigate and work on a fix.
- We'll credit you in the fix notes if you'd like, unless you ask us not to.
- Please give us a reasonable amount of time to fix the issue before any
  public disclosure.
