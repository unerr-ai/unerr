Rewind to a previous working state

```bash
unerr rewind [options] <entry-id>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `entry-id` | yes | — |

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--dry-run` | Only show blast radius without making changes | — |
