Compress text from stdin using graph-aware compression (for hooks)

```bash
unerr compress-output [options]
```

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--budget \<tokens\>` | Token budget | `2000` |
| `--no-graph` | Skip loading graph risk map | — |
