Review staged changes with the full engine (pre-commit gate)

```bash
unerr check-commit [options]
```

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--blocking` | Exit with code 1 on blocking findings (default: non-blocking) | — |
| `--verbose` | Show all evidence lines, not just the lead | — |
| `--record-verdict` | Post-commit: attach the pending review verdict to HEAD as a git note | — |
