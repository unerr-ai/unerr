Show the prompt ledger timeline

```bash
unerr timeline [options]
```

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--branch \<branch\>` | Filter by branch | — |
| `--tool \<tool\>` | Filter by tool name | — |
| `--limit \<n\>` | Number of entries to show | `50` |
