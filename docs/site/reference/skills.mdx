Manage unerr skills for your coding agent

```bash
unerr skills [command]
```

### `skills install`

Download and install recommended skills

```bash
unerr skills install [options]
```

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--ide \<ide\>` | IDE type (auto-detected if not specified) | — |

### `skills list`

List installed skills

```bash
unerr skills list
```
