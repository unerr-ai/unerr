Disable an opt-in feature (mcp-router)

```bash
unerr disable [options] <feature>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `feature` | yes | — |

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `-y, --yes` | Skip confirmation prompt | — |
