Generate business context (purpose, taxonomy, feature_area) for code entities via BYO-LLM

```bash
unerr enrich [options]
```

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--batch-size \<n\>` | Entities per LLM batch | `10` |
| `--limit \<n\>` | Max entities to enrich | — |
| `--force` | Re-enrich already-enriched entities | — |
| `--json` | Output results as JSON | — |
