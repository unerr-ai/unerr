Start local MCP server (deprecated — use 'unerr')

```bash
unerr serve [options]
```

**Options**

| Flag | Description | Default |
| --- | --- | --- |
| `--repo \<repoId\>` | Specific repo to serve | — |
| `--prefetch` | Enable predictive context pre-fetching | — |
| `--no-prefetch` | Disable predictive context pre-fetching | — |
